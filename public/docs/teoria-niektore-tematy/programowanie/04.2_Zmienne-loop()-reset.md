Zmodyfikuj szkic, dodając linię kodu na końcu funkcji loop tak, jak to zrobiono w poniższym kodzie. Uruchom szkic na płytce Arduino. Wciśnij przycisk Reset i obserwuj efekt działania szkicu.

```cpp
// Definicja zmiennych globalnych
int ledPin = 13;      // Pin 13 ma wbudowaną diodę LED na Arduino UNO [cite: 532, 533]
int delayPeriod = 100; // Początkowy czas opóźnienia w milisekundach 

void setup() {

  pinMode(ledPin, OUTPUT); 
}

void loop() {
  digitalWrite(ledPin, HIGH); // Włącz diodę (podaj 5V) [cite: 1156, 1182]
  delay(delayPeriod);         // Czekaj określony czas [cite: 1253]
  
  digitalWrite(ledPin, LOW);  // Wyłącz diodę (podaj 0V/GND) [cite: 1181, 1254]
  delay(delayPeriod);         // Czekaj ponownie [cite: 1258]
  
  // Zwiększ opóźnienie o 100 ms przy każdym powtórzeniu pętli 
  delayPeriod = delayPeriod + 100; 
}
```
