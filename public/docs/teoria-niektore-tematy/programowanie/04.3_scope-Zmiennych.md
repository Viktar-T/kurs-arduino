# Scope — zasięg zmiennych w C++ / Arduino

Zmienna istnieje tylko wewnątrz `{ }` w których została zadeklarowana.  
Klamra zamykająca `}` to granica — po jej przekroczeniu zmienna znika z pamięci.

---

## Prosty przykład — temperatura

Wyobraź sobie program który mierzy temperaturę i liczy ile razy była powyżej 30°C.

```cpp
// ── GLOBALNY ──────────────────────────────────────────
// widoczna w setup(), loop() i każdej innej funkcji
int liczbaAlarmow = 0;

void setup() {
    // ── LOKALNY w setup() ─────────────────────────────
    // istnieje tylko tutaj; po } ginie
    int pinCzujnika = A0;

    Serial.begin(9600);
    pinMode(pinCzujnika, INPUT);   // OK — pinCzujnika istnieje tutaj
}

void loop() {
    // ── LOKALNY w loop() ──────────────────────────────
    // tworzony przy każdym obiegu, niszczony na końcu
    float temperatura = analogRead(A0) * 0.48;

    if (temperatura > 30.0) {
        liczbaAlarmow = liczbaAlarmow + 1;  // OK — globalna
        Serial.println(liczbaAlarmow);
    }

    // Serial.println(pinCzujnika);  // BŁĄD — zadeklarowana w setup()
}                                    // temperatura ginie tutaj
```

Po każdym obiegu `loop()` zmienna `temperatura` znika — ale `liczbaAlarmow` **pamięta** swoją wartość, bo jest globalna.

---

## Dlaczego to ma znaczenie — porównanie

```cpp
// ❌ ŹLE — licznik lokalny, reset przy każdym obiegu
void loop() {
    int liczbaAlarmow = 0;    // zawsze zaczyna od zera!
    liczbaAlarmow = liczbaAlarmow + 1;
    Serial.println(liczbaAlarmow); // zawsze wyświetla: 1
}

// ✅ DOBRZE — licznik globalny, pamięta wartość
int liczbaAlarmow = 0;

void loop() {
    liczbaAlarmow = liczbaAlarmow + 1;
    Serial.println(liczbaAlarmow); // wyświetla: 1, 2, 3, 4...
}
```

---

## Tabela porównawcza

| Zasięg | Gdzie deklarujemy | Widoczna w | Żyje jak długo |
|---|---|---|---|
| Globalny | przed `setup()` | wszędzie | cały czas działania programu |
| Lokalny w `setup()` | wewnątrz `setup()` | tylko w `setup()` | do zamknięcia `}` setup() |
| Lokalny w `loop()` | wewnątrz `loop()` | tylko w `loop()` | jedna iteracja pętli |

---

## Zasada praktyczna

Zmienną deklaruj **tak nisko jak to możliwe** — lokalnie jeśli wystarczy, globalnie tylko gdy potrzeba:

- potrzebna w `loop()` i musi pamiętać wartość między obiegami → **globalna**
- potrzebna tylko do jednorazowej konfiguracji → **lokalna w `setup()`**
- potrzebna tylko na czas jednego przebiegu pętli → **lokalna w `loop()`**

---

## Błąd kompilatora przy złym zasięgu

```
error: 'pinCzujnika' was not declared in this scope
```

Ten komunikat oznacza dokładnie to: próbujesz użyć zmiennej poza jej `{ }`.

---

## Powiązane pojęcia

- **`const`** — zmienna tylko do odczytu; kompilator zgłosi błąd przy próbie zmiany wartości
- **`static` w funkcji** — lokalna, ale nie ginie między wywołaniami (zapamiętuje wartość)
- **shadowing** — lokalna zmienna o tej samej nazwie co globalna "przykrywa" globalną wewnątrz `{ }`
