# Tablice
Tablice służą do przechowywania zbioru zmiennych. Zmienne, które do tej pory poznałeś, przechowywały tylko jedną wartość. Zwykle była to wartość typu int. Tablica natomiast zawiera listę zmiennych. Korzystając z tej listy, możesz uzyskać dostęp do dowolnej wartości zapisanej w tablicy.

---
Podczas pracy z tablicami musisz zachować ostrożność. Kompilator nie powstrzyma próby uzyskania dostępu do danych znajdujących się poza obszarem tablicy. Dzieje się tak, ponieważ tablica jest tak naprawdę wskaźnikiem do adresu w pamięci, co pokazano na rysunku 5.2.

```cpp
int duration[] = {200, 200, 200, 500, 500, 500, 200, 200, 200};

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  for (int i=-4; i<=20; i++) {
    Serial.print(duration[i]);
    Serial.print(", ");
    delay(1000);
  }

}
```
