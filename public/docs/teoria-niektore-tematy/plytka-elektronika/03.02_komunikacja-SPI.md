# SPI — Serial Peripheral Interface

SPI to synchroniczny protokół komunikacji między masterem (Arduino) a jednym lub wieloma urządzeniami slave. Szybszy niż I2C, ale używa więcej przewodów.

## Przewody

| Pin | Nazwa | Kierunek | Opis |
|---|---|---|---|
| 11 | MOSI | Master → Slave | dane wysyłane przez Arduino |
| 12 | MISO | Slave → Master | dane odbierane przez Arduino |
| 13 | SCK | Master → Slave | zegar synchronizujący |
| 10 | SS/CS | Master → Slave | wybór urządzenia (aktywny LOW) |

Przy wielu urządzeniach slave — osobny pin SS dla każdego, MOSI/MISO/SCK wspólne.

## Użycie w Arduino

```cpp
#include <SPI.h>

void setup() {
    SPI.begin();
    pinMode(10, OUTPUT);     // SS pin jako wyjście
    digitalWrite(10, HIGH);  // slave nieaktywny
}

void wyslijBajt(byte dane) {
    digitalWrite(10, LOW);   // aktywuj slave
    SPI.transfer(dane);      // wyślij i odbierz jednocześnie
    digitalWrite(10, HIGH);  // zakończ transmisję
}
```

## Typowe urządzenia SPI

- Karty SD (`SD.h`)
- Wyświetlacze TFT (ILI9341, ST7735)
- Przetworniki DAC/ADC (MCP4921, MCP3204)
- Moduły radiowe (nRF24L01)
- Pamięci Flash (W25Q)

## Zalety i wady

Zalety: duża prędkość (kilka MHz), pełny duplex (jednoczesne wysyłanie i odbieranie), prosty protokół.

Wady: 4 przewody + osobny SS dla każdego slave, brak potwierdzenia odbioru (w przeciwieństwie do I2C).
