# PWM — wyjście pseudo-analogowe

PWM (Pulse Width Modulation — modulacja szerokości impulsu) pozwala symulować napięcie pośrednie na pinie cyfrowym. Arduino UNO nie ma prawdziwego wyjścia analogowego (DAC) — PWM to sprytne obejście.

## Jak działa PWM

Pin cyfrowy bardzo szybko przełącza się między HIGH (5V) a LOW (0V). Stosunek czasu HIGH do całego okresu to **wypełnienie (duty cycle)**:

```
Wypełnienie 25%:  ██░░░░░░░░░░  →  ~1.25V średnio
Wypełnienie 50%:  ██████░░░░░░  →  ~2.5V średnio
Wypełnienie 75%:  █████████░░░  →  ~3.75V średnio
Wypełnienie 100%: ████████████  →  5V (stały HIGH)
```

Częstotliwość PWM na UNO: ~490 Hz (piny 3,9,10,11) lub ~980 Hz (piny 5,6).

## Piny PWM na Arduino UNO

Oznaczone tyldą `~` na płytce: **3, 5, 6, 9, 10, 11**

## Funkcja `analogWrite()`
- wartosc: 0–255

```cpp
analogWrite(pin, wartosc);  // wartosc: 0–255
```

- `0` → wypełnienie 0% → 0V
- `127` → wypełnienie 50% → ~2.5V
- `255` → wypełnienie 100% → 5V

## Zastosowania PWM

```cpp
// Ściemnianie diody LED
analogWrite(9, 128);   // 50% jasności

// Sterowanie prędkością silnika DC (przez sterownik)
analogWrite(6, 200);   // ~78% prędkości

// Serwomechanizm (przez bibliotekę Servo)
// biblioteka Servo sama generuje odpowiedni sygnał PWM
```

## Czego PWM nie zastąpi

PWM nie jest prawdziwym napięciem analogowym — to szybkie przełączanie. Do zasilania czujników analogowych lub układów wymagających stabilnego napięcia pośredniego potrzebny jest filtr RC lub prawdziwy DAC (np. MCP4725 przez I2C).
