# badamy porty 3,3V; 5V 
![[../../../../../Pasted image 20260426061617.png|405]]
- wgrywamy program i 
- podłączamy pin 5 (wejście cyfrowe) do pinów zasilających (wyjść które generują różne napięcia na wyjściu):
	1. GN -> 0 0 0 0;
	2. 5 V -> 1 1 1 1;
	3. 3.3 V -> 1 1 1; - jęśli więcej niż 2.5 to generuje "1";
```cpp
const int inputPin = 5;

void setup() {

  pinMode(inputPin, INPUT);
  Serial.begin(9600);

}

void loop() {

  int reading = digitalRead(inputPin);
  Serial.print(reading);
  Serial.print(" ");
  delay(1000);

}
```
