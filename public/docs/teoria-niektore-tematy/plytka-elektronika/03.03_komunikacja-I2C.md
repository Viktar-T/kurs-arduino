# I2C — magistrala dwuprzewodowa

I2C (Inter-Integrated Circuit, wymawiane "I-kwadrat-C" lub "I2C") to protokół magistrali — wiele urządzeń na tylko **dwóch przewodach**. Każde urządzenie ma unikalny adres 7-bitowy.

## Przewody

| Pin Arduino UNO | Nazwa | Opis |
|---|---|---|
| A4 | SDA | dane (dwukierunkowe) |
| A5 | SCL | zegar (generowany przez master) |

Oba przewody wymagają **rezystorów podciągających** do 5V (zazwyczaj 4.7 kΩ — wiele modułów ma je wbudowane).

## Adresy urządzeń

Każde urządzenie I2C ma adres fabryczny (np. `0x68` dla MPU-6050). Niektóre pozwalają zmienić adres przez pin ADDR — można podłączyć dwa identyczne czujniki.

```cpp
#include <Wire.h>

void setup() {
    Wire.begin();         // inicjalizacja jako master
    Serial.begin(9600);
}

void loop() {
    Wire.beginTransmission(0x68);  // wybierz urządzenie pod adresem 0x68
    Wire.write(0x3B);              // rejestr do odczytu
    Wire.endTransmission(false);

    Wire.requestFrom(0x68, 6);     // poproś o 6 bajtów
    while (Wire.available()) {
        byte b = Wire.read();
        Serial.println(b);
    }
}
```

## Skanowanie adresów I2C

```cpp
#include <Wire.h>

void setup() {
    Wire.begin();
    Serial.begin(9600);

    for (byte addr = 8; addr < 127; addr++) {
        Wire.beginTransmission(addr);
        if (Wire.endTransmission() == 0) {
            Serial.print("Znaleziono urządzenie pod adresem: 0x");
            Serial.println(addr, HEX);
        }
    }
}
```

## Typowe urządzenia I2C

| Urządzenie | Adres | Co robi |
|---|---|---|
| LCD 16×2 + PCF8574 | 0x27 | wyświetlacz tekstowy |
| MPU-6050 | 0x68 | żyroskop + akcelerometr |
| BMP280 | 0x76 | ciśnienie + temperatura |
| SSD1306 OLED | 0x3C | wyświetlacz graficzny 128×64 |
| PCF8574 | 0x20–0x27 | ekspander I/O |

## Zalety i wady

Zalety: tylko 2 przewody, wiele urządzeń na tej samej magistrali, urządzenia mają adresy (łatwa identyfikacja).

Wady: wolniejszy niż SPI (100–400 kHz), pół-duplex, przy wielu urządzeniach może być trudno zarządzać adresami.
