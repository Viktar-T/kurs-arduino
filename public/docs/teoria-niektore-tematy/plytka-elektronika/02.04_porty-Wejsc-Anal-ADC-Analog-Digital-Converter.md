# Porty analogowe — wejście ADC
Przetwornik-Analogowo-​Cyfrowy

Arduino UNO ma 6 pinów analogowych wejściowych: **A0–A5**. Mierzą napięcie i zamieniają je na liczbę całkowitą — to przetwornik ADC (Analog-to-Digital Converter).

## Jak działa ADC

Przetwornik mierzy napięcie na pinie (0–5V) i zamienia je na wartość 10-bitową:

```
0V    →    0
2.5V  →  511
5V    → 1023
```

Rozdzielczość: 5V / 1024 kroków ≈ **4.88 mV na krok**

## Funkcja `analogRead()`

```cpp
int wartosc = analogRead(A0);  // zwraca 0–1023
```

Przeliczenie na napięcie:

```cpp
float napiecie = analogRead(A0) * (5.0 / 1023.0);
Serial.println(napiecie);  // np. 2.47
```

## Typowe czujniki na wejściu analogowym

| Czujnik | Co mierzy | Przykład odczytu |
|---|---|---|
| Potencjometr | Pozycja pokrętła | 0–1023 |
| LDR (fotorezystor) | Natężenie światła | ciemno→wysoko, jasno→nisko |
| NTC termistor | Temperatura | zależy od układu |
| Czujnik odległości GP2Y | Odległość | zależnie od modelu |

## Ważne szczegóły

- Piny A0–A5 mogą też działać jako **cyfrowe I/O** (`pinMode(A0, INPUT)`)
- Domyślne napięcie referencyjne: **5V** (można zmienić na `analogReference(INTERNAL)` → 1.1V dla większej precyzji przy małych napięciach)
- Czas pomiaru `analogRead()`: ~100 µs → max ~10 000 odczytów/sekundę
- Wejście bez podłączenia "pływa" — odczyty będą losowe; zawsze podłącz coś lub użyj rezystora podciągającego

## Przykład — odczyt napięcia i wysyłanie przez UART

```cpp
const byte analogPin = 0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int reading = analogRead(analogPin);
  float voltage = reading / 204.6;
  Serial.println(String("Odczyt: ") + voltage + " V;");
  delay(1000);
}
```

Przelicznik `204.6` to skrócony zapis: `1023 / 5V = 204.6` — dzięki temu `reading / 204.6` daje napięcie w Voltach.

Uwaga: w tym programie **nie ma `pinMode()`** — piny analogowe A0–A5 są domyślnie skonfigurowane jako wejścia analogowe i nie wymagają jawnego ustawienia trybu.

## Efekt "pływającego pinu" (floating pin)

Jeśli do A0 podłączymy przewód który **nie jest podłączony do niczego po drugiej stronie**, odczyty będą chaotyczne i losowe:

```
Odczyt: 0.85 V
Odczyt: 0.86 V
Odczyt: 2.92 V
Odczyt: 0.23 V
Odczyt: 3.65 V
```

**Dlaczego?** Luźny przewód działa jak antena — zbiera zakłócenia elektromagnetyczne z otoczenia (komputer, zasilacz, oświetlenie, ręka w pobliżu). ADC odczytuje elektryczny "szum" z powietrza zamiast prawdziwego sygnału.

**Testy do demonstracji dla uczniów:**

| Test | Podłączenie | Oczekiwany wynik |
|---|---|---|
| Pin do GND | A0 → GND | stałe `0.00 V` |
| Pin do 5V | A0 → 5V | stałe `~5.00 V` |
| Dotknięcie palcem | A0 → palec | chaotyczne skoki (ciało jako antena) |
| Luźny przewód | A0 → powietrze | losowe wartości |

> Wniosek: pin analogowy **zawsze musi być podłączony** do czegoś — czujnika, dzielnika napięcia, GND lub VCC.

# Teoria: ADC-Analog-Digital-Converter 
Przetwornik-Analogowo-​Cyfrowy
Jest to jedno z najpopularniejszych peryferiów występujących w mikrokontrolerach.
Jego zadaniem jest próbkowanie (считывание) napięcia podanego na wejście układu i przetwarzanie go na postać cyfrową. 
Przetwornik **8-bitowy**, ponieważ odczytana wartość mogła mieć **256 kombinacji** (poczynając od 0).
```cpp
Napięcie    => Wartość odczytana z ADC
      [V]           (zaokrąglona)
       0	=>	0
       ......
       5	=>	255
```
##### przetwornik ADC, który znajduje się w Arduino UNO jest **10-bitowy.**
```cpp
Napięcie    => Wartość odczytana z ADC
      [V]           (zaokrąglona)
       0	=>	0
       .......
       5	=>	1023
```

### wysoka Impendancja pinów Wejściowych
Mikrokontroler **ATmega328P**, który jest "mózgiem" Twojej płytki, posiada specjalnie zaprojektowane piny wejściowe (w tym piny analogowe od A0 do A5). Gdy pin pracuje jako wejście, znajduje się w stanie tzw. **wysokiej impedancji**.

Możesz o tym myśleć tak, jakby wewnątrz pinu **A5** ukryty był rezystor o gigantycznej wartości (dziesiątki milionów omów). Zgodnie z **Prawem Ohma** ($I = U/R$), jeśli przyłożysz do niego napięcie **5V**, popłynie przez niego mikroskopijnie mały, całkowicie bezpieczny prąd. Pin ten po prostu "nasłuchuje" (mierzy) potencjał elektryczny, nie obciążając źródła zasilania.
