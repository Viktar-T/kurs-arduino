# Rezystor podwyższający (pull-up)

## Po co w ogóle ten rezystor?

Pin Arduino w trybie `INPUT` ma **bardzo wysoką impedancję wejściową** (~100 MΩ). Działa jak czuły woltomierz — tylko "podgląda" napięcie, prądu praktycznie nie pobiera. To dobre do pomiaru, ale stwarza problem: jeśli pin nie jest do niczego podłączony, jego napięcie jest **nieokreślone**.

Mikrokontroler interpretuje napięcie tak:
- ~5 V → logiczna **1** (HIGH)
- ~0 V → logiczne **0** (LOW)
- napięcie pośrednie → **strefa nieokreślona** (raz HIGH, raz LOW)

---

## Problem: pływające wejście (floating input)

Obwód BEZ rezystora podwyższającego:

```
       Przycisk
GND ---o   o---- pin Arduino (INPUT)
```

| Stan przycisku | Co widzi pin | Odczyt |
|---|---|---|
| Wciśnięty | bezpośrednie połączenie z GND → 0 V | stabilne LOW ✅ |
| Puszczony | brak połączenia z czymkolwiek (floating) | losowe HIGH/LOW ❌ |

**Dlaczego puszczony przycisk daje losowe odczyty?**
Pin nie jest połączony z niczym i działa jak antena. Łapie:
- pole elektromagnetyczne sieci 50 Hz (przewody w ścianach)
- promieniowanie z monitora, ładowarki, telefonu
- przesłuchy między przewodami płytki stykowej
- nawet zbliżenie palca zmienia odczyt

Pin ma znikomą pojemność (kilka pF). Wzór $U = Q/C$ — bardzo mały ładunek na bardzo małej pojemności daje **duże skoki napięcia**. Stąd losowe wyniki na Serial Monitor.

---

## Rozwiązanie: rezystor podwyższający

```
           5V
           |
          [R] ← 10 kΩ (pull-up)
           |
           +---- pin Arduino (INPUT)
           |
        Przycisk
           |
          GND
```

### Stan 1: przycisk PUSZCZONY → pin = 5 V (HIGH)

Przycisk rozwarty → prąd nie płynie → na rezystorze **brak spadku napięcia** (prawo Ohma: $U = I \cdot R$, gdy $I = 0$, to $U = 0$).
Pin jest "trzymany" przy 5 V przez rezystor. Stąd nazwa: **podciąga** potencjał pinu do góry, do zasilania.

### Stan 2: przycisk WCIŚNIĘTY → pin = 0 V (LOW)

Tworzy się ścieżka: `5V → R (10 kΩ) → pin → przycisk → GND`
Prąd: $I = 5\text{V} / 10\text{kΩ} = 0{,}5$ mA.
Pin jest bezpośrednio zwarty z GND przez styki przycisku (~0,1 Ω). Z dzielnika napięcia:

$$U_{pin} = 5\text{V} \cdot \frac{0{,}1}{10\,000} \approx 0{,}00005\text{ V}$$

Praktycznie 0 V. Twardo i stabilnie.

---

## Dlaczego stan 0 V jest odporny na zakłócenia?

Tu jest sedno. Gdy pin jest połączony z GND przez przycisk, **GND jest źródłem o niskiej impedancji** — masa potrafi pochłonąć lub dostarczyć dużo prądu nie zmieniając swojego napięcia.

Zakłócenie indukuje na pinie mikroamperowy prąd. Spadek napięcia na pinie:

$$\Delta U = I_{zakł} \cdot Z$$

| Sytuacja | Impedancja Z | Wpływ zakłócenia 1 µA |
|---|---|---|
| Pin pływający | ~10 MΩ | $\Delta U$ = 10 V (katastrofa) |
| Pin z pull-upem (puszczony) | 10 kΩ | $\Delta U$ = 10 mV (niezauważalne) |
| Pin zwarty z GND (wciśnięty) | ~0 Ω | $\Delta U$ ≈ 0 (idealnie) |

**Analogia hydrauliczna:**
- pływające wejście = kropla wody na suchej skale (każdy podmuch ją przewraca)
- pin zwarty z GND = kropla w oceanie (ocean nie zauważa)

---

## Krótko o impedancji

**Impedancja Z** (w omach) — "opór" stawiany prądowi zmiennemu i szybkim zmianom sygnału. Uogólnienie rezystancji.

- **Niska impedancja = "twarde" źródło** — utrzymuje napięcie nawet pod obciążeniem (GND, wyjście Arduino, zasilacz)
- **Wysoka impedancja = "miękkie" źródło** — napięcie łatwo się zmienia (pin pływający, antena)

| Punkt obwodu | Impedancja | Charakter |
|---|---|---|
| Pin INPUT (bez pull-upa) | ~100 MΩ | wrażliwy, łapie zakłócenia |
| Pin INPUT_PULLUP (wbudowany) | ~20–50 kΩ | umiarkowany, stabilny |
| Pin OUTPUT (HIGH/LOW) | ~25–40 Ω | "twardy" |
| Masa (GND) | ~0 Ω | idealna referencja |

**Trzy zasady do zapamiętania:**
1. Wejście ma wysoką impedancję — łatwo zaburzyć, dlatego mierzymy nim napięcie.
2. Wyjście ma niską impedancję — narzuca napięcie obwodowi, dlatego sterujemy.
3. Nie wolno zwierać dwóch wyjść (jedno HIGH, drugie LOW) — zwarcie spali pin.

## Logika odwrócona (active-low) — uwaga!

Z pull-upem mamy **paradoks intuicji**:

| Przycisk | Stan logiczny |
|---|---|
| Wciśnięty | **LOW (0)** |
| Puszczony | **HIGH (1)** |

W kodzie:
```cpp
if (digitalRead(BUTTON_PIN) == LOW) {
  // przycisk został wciśnięty
}
```

---

## Praktyka: wbudowany pull-up Arduino

Arduino ma **wbudowane rezystory pull-up** (~20–50 kΩ). Nie trzeba zewnętrznego rezystora — wystarczy przycisk między pinem a GND.

```cpp
const int buttonPin = 2;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);  // ← włącza wewnętrzny pull-up
  Serial.begin(9600);
}

void loop() {
  int state = digitalRead(buttonPin);
  if (state == LOW) {
    Serial.println("Przycisk wcisniety");
  } else {
    Serial.println("Przycisk puszczony");
  }
  delay(200);
}
```

---

## Ćwiczenie pokazowe dla uczniów

1. Najpierw `pinMode(buttonPin, INPUT)` **bez** rezystora — przycisk między pinem a GND. Otworzyć Serial Monitor → uczniowie zobaczą **losowe odczyty** przy puszczonym przycisku.
2. Zmienić na `INPUT_PULLUP` — bez zmiany okablowania. Odczyty stają się **stabilne**.
3. Wniosek: pin musi mieć zdefiniowany potencjał — albo przez przycisk (LOW), albo przez pull-up (HIGH).

---

## Dlaczego akurat 10 kΩ?

Klasyczny kompromis:
- za mały (np. 100 Ω) → 50 mA przy wciśniętym przycisku, niepotrzebne grzanie
- za duży (np. 1 MΩ) → pin staje się znów wrażliwy na zakłócenia ("miękki" pull-up)
- 10 kΩ → prąd ~0,5 mA, impedancja wystarczająco niska, by zakłócenia nie miały szans

Wbudowany pull-up Arduino ma 20–50 kΩ — działa dobrze w typowych warunkach laboratoryjnych.

---

## Podsumowanie w jednym zdaniu

Rezystor podwyższający daje pinowi **zdefiniowany potencjał** (5 V) gdy żadne inne źródło go nie narzuca; gdy przycisk zewrze pin do GND, niska impedancja masy "pochłania" zakłócenia i daje stabilne 0 V. Bez pull-upa pin "wisi w powietrzu" i działa jak antena.
