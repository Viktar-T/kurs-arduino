## 1. Rysowanie wykresów z Arduino

## 2. Wykres odległości od przeszkody

Teraz wyślemy dane z czujnika HC-SR04 do Plottera. Podłącz czujnik tak samo jak w lekcji 12 (`trigPin = 12`, `echoPin = 11`):

<Code lang="cpp" file="hc-sr04-wykres.ino">
```cpp
#define trigPin 12
#define echoPin 11

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  long czas, dystans;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  czas = pulseIn(echoPin, HIGH);
  dystans = czas / 58;

  Serial.println(dystans);
  delay(100);
}
```
</Code>

Gdy nic nie stoi przed czujnikiem, `pulseIn()` czeka na echo zbyt długo i zwraca `0` albo bardzo dużą wartość. Widać to na wykresie jako piki:

Naprawmy to: ograniczmy maksymalną wartość do zakresu podawanego przez producenta (400 cm):

<Code lang="cpp" file="hc-sr04-wykres-poprawiony.ino">
```cpp
#define trigPin 12
#define echoPin 11

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  long czas, dystans;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  czas = pulseIn(echoPin, HIGH);
  dystans = czas / 58;

  if (dystans > 400) {
    dystans = 400;
  }

  Serial.println(dystans);
  delay(100);
}
```
</Code>

### Losowe ziarno — `randomSeed()`

<Expandable title="Zakres z dolnym limitem: random(a, b)" heading="###">

`random(300)` daje zakres `0–299`. Jeśli chcesz zakres `10–99`, użyj:

```cpp
random(10, 100)   // wynik: 10, 11, ..., 99
```

Obie formy można mieszać: `random(50)` i `random(10, 50)` to różne zakresy.

</Expandable>

## 5. Losowe miganie diodą

Łączymy liczby losowe z PWM i pętlą główną, żeby dioda migała w nieprzewidywalny sposób:

<Code lang="cpp" file="losowe-miganie.ino">
```cpp
void setup() {
  pinMode(13, OUTPUT);
  randomSeed(analogRead(0));
}

void loop() {
  int czasWlaczona = random(10, 100) * 10;  // 100–990 ms, skok co 10
  int czasWylaczona = random(5, 50) * 10;   // 50–490 ms, skok co 10

  digitalWrite(13, HIGH);
  delay(czasWlaczona);
  digitalWrite(13, LOW);
  delay(czasWylaczona);
}
```
</Code>

## 6. Łączenie instrukcji warunkowych

Operator `||` to **lub** — warunek jest spełniony, gdy przynajmniej jedna część jest prawdziwa. Operator `&&` to **i** — obie muszą być prawdziwe.

<Schematic
  src="/img/lekcje/dzien-01/13.16-schemat-przyciski-diody.png"
  caption="Schemat układu: dwa przyciski (piny 9 i 10) i dwie diody LED (piny 7 i 8)."
  alt="Schemat elektryczny z dwoma przyciskami i dwiema diodami LED podłączonymi do Arduino"
  width={600}
  height={400}
/>

Podłącz dwa przyciski do pinów `9` i `10` (z `INPUT_PULLUP`), a dwie diody do pinów `7` i `8`.

### Operator OR — dioda zielona

Dioda zielona (pin `8`) świeci, gdy **którykolwiek** przycisk jest wciśnięty:

<Code lang="cpp" file="warunki-or.ino">
```cpp
void setup() {
  pinMode(10, INPUT_PULLUP);
  pinMode(9, INPUT_PULLUP);
  pinMode(8, OUTPUT);
  pinMode(7, OUTPUT);
  digitalWrite(8, LOW);
  digitalWrite(7, LOW);
}

void loop() {
  if (digitalRead(9) == LOW || digitalRead(10) == LOW) {
    digitalWrite(8, HIGH);
  } else {
    digitalWrite(8, LOW);
  }
}
```
</Code>

### Operator AND — dioda czerwona

Dioda czerwona (pin `7`) świeci tylko wtedy, gdy **oba** przyciski są wciśnięte jednocześnie:

<Code lang="cpp" file="warunki-and-or.ino">
```cpp
void setup() {
  pinMode(10, INPUT_PULLUP);
  pinMode(9, INPUT_PULLUP);
  pinMode(8, OUTPUT);
  pinMode(7, OUTPUT);
  digitalWrite(8, LOW);
  digitalWrite(7, LOW);
}

void loop() {
  if (digitalRead(9) == LOW || digitalRead(10) == LOW) {
    digitalWrite(8, HIGH);
  } else {
    digitalWrite(8, LOW);
  }

  if (digitalRead(9) == LOW && digitalRead(10) == LOW) {
    digitalWrite(7, HIGH);
  } else {
    digitalWrite(7, LOW);
  }
}
```
</Code>

## 7. Warunki w praktyce — alarm z czujnikiem i przyciskiem

Połączmy to wszystko. Program włącza buzzer, gdy obiekt jest w odległości 20–40 cm **lub** gdy przycisk jest wciśnięty — alarm działa zarówno automatycznie, jak i ręcznie:

<Photo
  file="13.17-montaz-czujnik-buzzer.jpg"
  day="dzien-01"
  caption="Układ z czujnikiem HC-SR04, przyciskiem i buzzerem."
  alt="Fotografia zmontowanego układu: Arduino, HC-SR04, przycisk i buzzer"
  width={650}
  height={433}
/>

<Code lang="cpp" file="alarm-czujnik-przycisk.ino">
```cpp
#define trigPin 12
#define echoPin 9

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(10, INPUT_PULLUP);  // Przycisk
  pinMode(11, OUTPUT);        // Buzzer
  digitalWrite(11, LOW);
}

void loop() {
  long czas, dystans;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  czas = pulseIn(echoPin, HIGH);
  dystans = czas / 58;

  if ((dystans > 20 && dystans < 40) || digitalRead(10) == LOW) {
    digitalWrite(11, HIGH);
  } else {
    digitalWrite(11, LOW);
  }
}
```
</Code>

<Callout type="tip" title="Czytaj warunek od prawej do lewej">
`(dystans > 20 && dystans < 40) || digitalRead(10) == LOW` — najpierw sprawdzamy, czy dystans mieści się w oknie 20–40 cm, a potem, czy przycisk jest wciśnięty. Wystarczy jeden z tych faktów, żeby alarm zadziałał.
</Callout>

<MiniProject title="System parkowania" estimate="20 min">

Zbuduj uproszczony system pomocy parkowania:
- Odległość > 40 cm: cisza, dioda zielona.
- Odległość 20–40 cm: dioda żółta, buzzer „pika" wolno (1 sek. przerwy).
- Odległość < 20 cm: dioda czerwona, buzzer „pika" szybko (200 ms przerwy).

Skorzystaj z funkcji `zmierzOdleglosc()` z poprzedniej lekcji i warunków `if-else if-else`.

## Podsumowanie

Serial Plotter przekształca liczby z `Serial.println()` w wykres — wystarczy zamienić tekst na gołe cyfry. Kilka serii jednocześnie oddzielasz tabulatorami. Liczby losowe (`random()`) ożywiają efekty świetlne i gry, a `randomSeed(analogRead(0))` sprawia, że każde uruchomienie daje inną sekwencję. Operatory `&&` i `||` pozwalają łączyć wiele warunków w jednej decyzji: czujnik i przycisk mogą razem decydować, czy alarm ma zabrzmieć. To solidna baza do własnych projektów — każdy z tych elementów możesz teraz łączyć swobodnie.
