W tej lekcji nauczysz się obsługiwać **klawiaturę matrycową 4×4** za pomocą biblioteki `Keypad`, a następnie wykorzystasz ją do zbudowania własnej **centralki alarmowej**. System będzie składał się z czterech stanów: czuwanie, monitorowanie, rozbrajanie i aktywny alarm. Do jego realizacji połączymy razem elementy poznane w poprzednich lekcjach — linijkę WS2812, czujnik PIR, kontaktron i buzzer.

## 1. Jak działa klawiatura matrycowa

Klawiatura numeryczna to wygodny sposób na wprowadzanie danych do Arduino. Popularny model 4×4 ma **16 klawiszy**, ale wymaga tylko **8 wyprowadzeń** — dzięki matrycowej organizacji styków.

<Photo
  file="17.01-klawiatura-numeryczna-przyklad.jpg"
  caption="Przykład klawiatury numerycznej — 16 przycisków podłączonych do Arduino zaledwie 8 przewodami."
  alt="Zdjęcie klawiatury numerycznej 4x4"
/>

Wewnątrz klawiatura jest zorganizowana w **wiersze i kolumny**. Każdy klawisz łączy jeden wiersz z jedną kolumną. Arduino wysyła sygnał kolejno przez każdy wiersz i sprawdza, który klawisz jest wciśnięty, odczytując stan kolumn — to technika zwana **skanowaniem matrycy**.

<Photo
  file="17.02-klawiatura-numeryczna-wnetrze.jpg"
  caption="Wewnętrzne połączenie sygnałów w klawiaturze — 4 wiersze × 4 kolumny = 16 przycisków, 8 wyprowadzeń."
  alt="Schemat wewnętrznych połączeń klawiatury matrycowej 4x4"
/>

<Expandable title="Głębiej: jak Arduino skanuje matrycę klawiatury?" heading="####">

Klawiatura 4×4 nie wysyła gotowego numeru klawisza. W środku każdy przycisk jest tylko połączeniem jednego wiersza z jedną kolumną. Arduino musi więc aktywować wiersze po kolei i sprawdzać, na której kolumnie pojawiła się zmiana stanu.

Przykład: jeśli program aktywuje wiersz R2 i widzi sygnał na kolumnie C3, to wie, że naciśnięto klawisz leżący na przecięciu R2 i C3. Biblioteka `Keypad` wykonuje to skanowanie bardzo szybko, filtruje drgania styków i zwraca gotowy znak przez `getKey()`.

Przy wielu jednoczesnych naciśnięciach mogą pojawić się niejednoznaczności, bo kilka połączeń w matrycy tworzy dodatkowe ścieżki prądu. Profesjonalne klawiatury rozwiązują to diodami przy każdym klawiszu, ale w prostych klawiaturach Arduino zwykle zakładamy naciskanie jednego klawisza naraz.

</Expandable>

## 4. Biblioteka Keypad — konfiguracja

Do obsługi klawiatury używamy biblioteki `Keypad.h`. Trzeba ją najpierw zainstalować w Arduino IDE: **Szkic → Dołącz bibliotekę → Zarządzaj bibliotekami** → wyszukaj `Keypad` autora Mark Stanley.

Konfiguracja biblioteki wymaga trzech kroków: deklaracji pinów, mapy klawiszy i inicjalizacji obiektu.

**Krok 1 — deklaracja pinów:**

```cpp
#include <Keypad.h> // Biblioteka obsługi klawiatury

const byte ROWS = 4; // Liczba wierszy
const byte COLS = 4; // Liczba kolumn

byte rowPins[ROWS] = {5, 4, 3, 2}; // Piny wierszy
byte colPins[COLS] = {6, 7, 8, 9}; // Piny kolumn
```

**Krok 2 — mapa klawiszy:**

```cpp
char keys[ROWS][COLS] = { // Mapowanie klawiszy na znaki
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};
```

  file="17.08-mapowanie-klawiszy.png"

/>

**Krok 3 — inicjalizacja obiektu:**

```cpp

```

## 5. Pierwszy program — odczyt klawiatury przez UART

Funkcja `klawiatura.getKey()` zwraca znak wciśniętego klawisza lub `0`, jeśli żaden klawisz nie jest naciśnięty. Poniższy program drukuje wciśnięty klawisz w Monitorze portu szeregowego:

<Code lang="cpp" file="klawiatura-test.ino">
```cpp
#include <Keypad.h> // Biblioteka obsługi klawiatury

const byte ROWS = 4; // Liczba wierszy
const byte COLS = 4; // Liczba kolumn

byte rowPins[ROWS] = {5, 4, 3, 2}; // Piny wierszy
byte colPins[COLS] = {6, 7, 8, 9}; // Piny kolumn

char keys[ROWS][COLS] = { // Mapowanie klawiszy
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

Keypad klawiatura = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

void setup() {
  Serial.begin(9600);
}

void loop() {
  char klawisz = klawiatura.getKey(); // Odczytaj wciśnięty klawisz

  if (klawisz) { // Jeśli klawisz został wciśnięty (wartość != 0)
    Serial.println(klawisz);
  }
}
```
</Code>

## 7. Szkielet kodu — automat stanów

Zaczynamy od zbudowania szkieletu programu z pustymi blokami `case`. Zmienna `stanAlarmu` przechowuje bieżący stan i decyduje, który blok wykonuje się w pętli `loop()`:

<Code lang="cpp" file="centralka-szkielet.ino">
```cpp
const byte BUZZER = 11;
const byte KONTAKTRON = 10;
const byte PIR = 1;

#include <Keypad.h>            // Biblioteka obsługi klawiatury
#include <Adafruit_NeoPixel.h> // Biblioteka linijki LED

const byte ROWS = 4;
const byte COLS = 4;

byte rowPins[ROWS] = {5, 4, 3, 2};
byte colPins[COLS] = {6, 7, 8, 9};

char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

Keypad klawiatura = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);
Adafruit_NeoPixel linijka = Adafruit_NeoPixel(8, A0, NEO_GRB + NEO_KHZ800);

volatile int stanAlarmu = 1; // Stan początkowy: czuwanie

void setup() {
  pinMode(BUZZER, OUTPUT);
  pinMode(KONTAKTRON, INPUT_PULLUP);
  pinMode(PIR, INPUT_PULLUP);
  linijka.begin();
  linijka.show();
}

void loop() {
  switch (stanAlarmu) { // Wykonaj akcje odpowiednie dla bieżącego stanu
    case 1:
      // Czuwanie
    break;

    case 2:
      // Monitorowanie
    break;

    case 3:
      // Rozbrajanie
    break;

    case 4:
      // Sygnalizacja alarmu
    break;
  }
}
```
</Code>

<Callout type="note" title="Dlaczego switch-case, a nie if-else?">
Automat stanów z `switch-case` jest czytelniejszy i łatwiejszy w rozbudowie niż zagnieżdżone bloki `if-else`. Każdy stan jest wyraźnie oddzielony. Zmiana stanu polega tylko na przypisaniu nowej wartości do `stanAlarmu`.
</Callout>

## 8. Stan 1 — czuwanie

W stanie czuwania pierwsza dioda linijki świeci na **zielono**. Alarm uzbraja się po naciśnięciu klawisza `A` — przez ~10 sekund diody zapalają się kolejno na niebiesko, potem na czerwono (odliczanie), a następnie system przechodzi do monitorowania:

<Code lang="cpp" file="centralka-stan1.ino">
```cpp
void loop() {
  char klawisz = 0; // Zmienna na wciśnięty klawisz
  int i = 0;        // Zmienna pomocnicza do pętli

  switch (stanAlarmu) {
    case 1:
      // Czuwanie — zielona dioda
      linijka.setPixelColor(0, linijka.Color(0, 15, 0)); // Dioda 1 zielona
      linijka.show();

      klawisz = klawiatura.getKey();
      if (klawisz == 'A') { // Uzbrajamy alarm klawiszem A
        for (i = 1; i < 8; i++) {
          linijka.setPixelColor(i, linijka.Color(0, 0, 15)); // Kolejne diody na niebiesko
          linijka.show();
          delay(710); // ~5 sekund łącznie
        }
        for (i = 1; i < 8; i++) {
          linijka.setPixelColor(i, linijka.Color(15, 0, 0)); // Kolejne diody na czerwono
          linijka.show();
          delay(710); // ~5 sekund łącznie
        }
        wylaczDiody();
        stanAlarmu = 2; // Przejście do monitorowania
      }
    break;

    case 2:
      // Monitorowanie — dioda 8 miga na czerwono
      linijka.setPixelColor(7, linijka.Color(15, 0, 0));
      linijka.show();
      delay(50);
      linijka.setPixelColor(7, linijka.Color(0, 0, 0));
      linijka.show();
      delay(50);
    break;

    // ... pozostałe stany
  }
}

void wylaczDiody() {
  for (int i = 0; i < 8; i++) {
    linijka.setPixelColor(i, linijka.Color(0, 0, 0)); // Wyłącz diodę i
  }
  linijka.show();
}
```
</Code>

## 9. Stan 2 — monitorowanie

System sprawdza czujniki w każdej iteracji pętli. Wykrycie ruchu przez PIR uruchamia alarm **natychmiast** (stan 4). Otwarcie okna/drzwi przez kontaktron daje użytkownikowi chwilę na wpisanie PIN (stan 3):

<Code lang="cpp" file="centralka-stan2.ino">
```cpp
case 2:
  // Monitorowanie — dioda 8 miga na czerwono
  linijka.setPixelColor(7, linijka.Color(15, 0, 0));
  linijka.show();
  delay(50);
  linijka.setPixelColor(7, linijka.Color(0, 0, 0));
  linijka.show();
  delay(50);

  if (digitalRead(PIR) == HIGH) {
    stanAlarmu = 4; // Ruch wykryty — alarm natychmiast
  } else if (digitalRead(KONTAKTRON) == HIGH) {
    stanAlarmu = 3; // Kontaktron — szansa na rozbrojenie
  }
break;
```
</Code>

<Callout type="warning" title="PIR a kontaktron — różny priorytet">
Czujnik PIR wykrywa ruch wewnątrz pomieszczenia — zakładamy, że to już intruz, więc alarm uruchamia się bez szansy na rozbrojenie. Kontaktron reaguje na otwarcie okna/drzwi — to może być właściciel wracający do domu, dlatego dostaje czas na wpisanie PIN.
</Callout>

## 10. Stan 3 — rozbrajanie (wpisywanie PIN)

Stan rozbrajania sprawdza kolejne cyfry kodu PIN. Jeśli wszystkie cztery cyfry są poprawne, system wraca do czuwania. Błędna cyfra lub przekroczenie czasu (50 iteracji × 100 ms = 5 sekund) uruchamia alarm:

<Code lang="cpp" file="centralka-stan3.ino">
```cpp
case 3:
  // Rozbrajanie — oczekiwanie na poprawny PIN
  klawisz = klawiatura.getKey();
  if (klawisz) {
    if (pinAlarmuPozycja == 1 && klawisz == pinCyfra1) {
      pinAlarmuPozycja++;
    } else if (pinAlarmuPozycja == 2 && klawisz == pinCyfra2) {
      pinAlarmuPozycja++;
    } else if (pinAlarmuPozycja == 3 && klawisz == pinCyfra3) {
      pinAlarmuPozycja++;
    } else if (pinAlarmuPozycja == 4 && klawisz == pinCyfra4) {
      stanAlarmu = 1;        // Poprawny PIN — powrót do czuwania
      pinAlarmuPozycja = 1;  // Reset pozycji PIN
    } else {
      stanAlarmu = 4;        // Błędna cyfra — alarm
      pinAlarmuPozycja = 1;
    }
  }

  delay(100);
  ileCzasuMinelo++;          // Odliczanie czasu (1 iteracja = 100 ms)
  if (ileCzasuMinelo >= 50) {
    stanAlarmu = 4;          // Czas minął — alarm
  }
break;
```
</Code>

## 11. Stan 4 — sygnalizacja alarmu

Alarm sygnalizuje zagrożenie naprzemiennym miganiem **czerwonym i niebieskim** na całej linijce oraz syreną dźwiękową na buzzerze:

<Code lang="cpp" file="centralka-stan4.ino">
```cpp
case 4:
  // Sygnalizacja — czerwone i niebieskie miganie z syreną
  for (i = 0; i < 8; i++) {
    linijka.setPixelColor(i, linijka.Color(255, 0, 0)); // Wszystkie czerwone
  }
  linijka.show();
  tone(BUZZER, 4300); // Wysoki ton syreny
  delay(100);

  for (i = 0; i < 8; i++) {
    linijka.setPixelColor(i, linijka.Color(0, 0, 255)); // Wszystkie niebieskie
  }
  linijka.show();
  tone(BUZZER, 3500); // Niski ton syreny
  delay(100);
break;
```
</Code>

<Callout type="tip" title="Jak używać Pomocnika AI do nauki programowania">
Maszyna stanów i klawiatury to obszar, gdzie AI może pomóc w projektowaniu i rozszerzaniu logiki:

- **Zrozumienie maszyny stanów** — zapytaj AI: „Wytłumacz koncepcję maszyny stanów (state machine) na przykładzie systemu alarmowego z czterema stanami: czuwanie, monitorowanie, rozbrajanie, alarm". AI narysuje diagram przejść i wytłumaczy, dlaczego `switch-case` jest naturalnym narzędziem do implementacji.
- **Dodawanie nowych stanów** — poproś AI: „Do mojej centralki alarmowej chcę dodać 5. stan: 'testowanie' — w tym stanie wszystkie czujniki są aktywne, ale alarm nie włącza się. Jak rozszerzyć kod o ten stan?". To ćwiczenie pokazuje skalowalność maszyny stanów.
- **Rozszerzenie logiki PIN** — opisz AI: „Moja centrala sprawdza tylko 4-cyfrowy PIN. Jak dodać blokadę po 3 błędnych próbach i odblokowanie specjalnym kodem?". Takie rozszerzenia uczą programowania defensywnego i obsługi stanów błędu.
</Callout>

## 12. Kompletny kod centralki alarmowej

Poniżej pełny, działający program łączący wszystkie cztery stany:

<Code lang="cpp" file="centralka-alarmowa.ino">
```cpp
const byte BUZZER = 11;
const byte KONTAKTRON = 10;
const byte PIR = 1;

#include <Keypad.h>
#include <Adafruit_NeoPixel.h>

const byte ROWS = 4;
const byte COLS = 4;

byte rowPins[ROWS] = {5, 4, 3, 2};
byte colPins[COLS] = {6, 7, 8, 9};

char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

Keypad klawiatura = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);
Adafruit_NeoPixel linijka = Adafruit_NeoPixel(8, A0, NEO_GRB + NEO_KHZ800);

volatile int stanAlarmu = 1; // Stan początkowy: czuwanie
int pinAlarmuPozycja = 1;    // Aktualnie sprawdzana pozycja PIN
char pinCyfra1 = '1';        // Pierwsza cyfra PIN
char pinCyfra2 = '2';        // Druga cyfra PIN
char pinCyfra3 = '3';        // Trzecia cyfra PIN
char pinCyfra4 = '4';        // Czwarta cyfra PIN
int ileCzasuMinelo = 0;      // Licznik czasu w stanie rozbrajania

void setup() {
  pinMode(BUZZER, OUTPUT);
  pinMode(KONTAKTRON, INPUT_PULLUP);
  pinMode(PIR, INPUT_PULLUP);
  linijka.begin();
  linijka.show();
}

void loop() {
  char klawisz = 0;
  int i = 0;

  switch (stanAlarmu) {
    case 1:
      // Czuwanie — zielona dioda, klawisz A uzbraja alarm
      linijka.setPixelColor(0, linijka.Color(0, 15, 0));
      linijka.show();

      klawisz = klawiatura.getKey();
      if (klawisz == 'A') {
        for (i = 1; i < 8; i++) {
          linijka.setPixelColor(i, linijka.Color(0, 0, 15)); // Niebieskie odliczanie
          linijka.show();
          delay(710);
        }
        for (i = 1; i < 8; i++) {
          linijka.setPixelColor(i, linijka.Color(15, 0, 0)); // Czerwone odliczanie
          linijka.show();
          delay(710);
        }
        wylaczDiody();
        stanAlarmu = 2;
      }
    break;

    case 2:
      // Monitorowanie — dioda 8 miga na czerwono, czujniki aktywne
      linijka.setPixelColor(7, linijka.Color(15, 0, 0));
      linijka.show();
      delay(50);
      linijka.setPixelColor(7, linijka.Color(0, 0, 0));
      linijka.show();
      delay(50);

      if (digitalRead(PIR) == HIGH) {
        stanAlarmu = 4;          // Ruch — alarm natychmiast
      } else if (digitalRead(KONTAKTRON) == HIGH) {
        ileCzasuMinelo = 0;      // Reset odliczania
        stanAlarmu = 3;          // Kontaktron — szansa na rozbrojenie
      }
    break;

    case 3:
      // Rozbrajanie — 5 sekund na wpisanie poprawnego PIN
      klawisz = klawiatura.getKey();
      if (klawisz) {
        if (pinAlarmuPozycja == 1 && klawisz == pinCyfra1) {
          pinAlarmuPozycja++;
        } else if (pinAlarmuPozycja == 2 && klawisz == pinCyfra2) {
          pinAlarmuPozycja++;
        } else if (pinAlarmuPozycja == 3 && klawisz == pinCyfra3) {
          pinAlarmuPozycja++;
        } else if (pinAlarmuPozycja == 4 && klawisz == pinCyfra4) {
          stanAlarmu = 1;
          pinAlarmuPozycja = 1;
        } else {
          stanAlarmu = 4;        // Błędna cyfra — alarm
          pinAlarmuPozycja = 1;
        }
      }

      delay(100);
      ileCzasuMinelo++;
      if (ileCzasuMinelo >= 50) { // 50 × 100 ms = 5 sekund
        stanAlarmu = 4;
      }
    break;

    case 4:
      // Sygnalizacja alarmu — syrena + naprzemienne LED
      for (i = 0; i < 8; i++) {
        linijka.setPixelColor(i, linijka.Color(255, 0, 0)); // Wszystkie czerwone
      }
      linijka.show();
      tone(BUZZER, 4300);
      delay(100);

      for (i = 0; i < 8; i++) {
        linijka.setPixelColor(i, linijka.Color(0, 0, 255)); // Wszystkie niebieskie
      }
      linijka.show();
      tone(BUZZER, 3500);
      delay(100);
    break;
  }
}

void wylaczDiody() {
  for (int i = 0; i < 8; i++) {
    linijka.setPixelColor(i, linijka.Color(0, 0, 0));
  }
  linijka.show();
}
```

## Podsumowanie

Klawiatura matrycowa 4×4 komunikuje się z Arduino przez **8 wyprowadzeń** — cztery wiersze i cztery kolumny — dzięki czemu 16 klawiszy nie zajmuje 16 pinów. Biblioteka `Keypad` automatycznie obsługuje skanowanie matrycy; wystarczy zadeklarować piny, mapę znaków i wywołać `getKey()` w pętli. Centralka alarmowa bazuje na **automacie stanów** zbudowanym ze `switch-case` i zmiennej `stanAlarmu` — każdy stan wykonuje tylko swoje operacje i w odpowiednim momencie zmienia wartość tej zmiennej, przenosząc program do kolejnego stanu. Taka architektura jest czytelna, łatwa w rozbudowie i eliminuje potrzebę stosowania przerwań do większości zadań czasu rzeczywistego.
