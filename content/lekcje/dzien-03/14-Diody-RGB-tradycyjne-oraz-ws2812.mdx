Diody świecące znajdują zastosowanie w każdym projekcie. Często oprócz prostej sygnalizacji stanu urządzenia zależy nam na efektach wizualnych. W tej lekcji poznamy dwa podejścia do sterowania kolorowymi diodami RGB (Red, Green, Blue — czerwony, zielony, niebieski): klasyczne (trzy osobne kanały, PWM (Pulse Width Modulation, modulacja szerokości impulsu)) oraz nowoczesne (diody programowalne WS2812 ze zintegrowanym sterownikiem i biblioteką NeoPixel).

## 1. Czym są diody programowalne?

Diody programowalne, nazywane czasem inteligentnymi, mogą być elementami zagadkowymi dla wielu początkujących. Jak objawia się ich „inteligencja"? W każdej diodzie WS2812 producent zamieścił miniaturowy układ sterujący, który potrafi odebrać dane z Arduino przez **jeden przewód sygnałowy** i na ich podstawie ustawić jasność trzech barw (R, G, B). Dzięki temu możemy kontrolować setki diod, używając tylko jednego pinu Arduino.

<Callout type="note" title="WS2812 vs tradycyjna dioda RGB">
Tradycyjna dioda RGB wymaga **3 pinów Arduino** (po jednym na kolor) i 3 rezystorów. Dioda WS2812 wymaga tylko **1 pinu danych** — niezależnie od tego, ile diod podłączysz w szereg.
</Callout>

## 3. Diody RGB — podejście tradycyjne

Diody RGB (ang. *Red, Green, Blue*) mają w swoim wnętrzu trzy struktury świecące — czerwoną, zieloną i niebieską. Sterując niezależnie każdą z nich, możemy uzyskać dowolny kolor.

</Callout>

### 3.1 Pierwsze użycie diody RGB

Podłącz diodę RGB do pinów 3, 5 i 6 (wszystkie obsługują PWM), każdy przez rezystor 1 kΩ. Masę podłącz do GND.

  width={700}

Pierwszy szkic zaświeci każdy kolor po kolei, potem połączy je razem, a na końcu wyłączy wszystkie:

<Code lang="cpp" file="rgb-pierwsze-kolory.ino">
```cpp
#define czerwona 3
#define zielona 5
#define niebieska 6

void setup() {
  pinMode(czerwona, OUTPUT); // Piny podłączone do diody jako wyjścia
  pinMode(zielona, OUTPUT);
  pinMode(niebieska, OUTPUT);
}

void loop() {
  digitalWrite(czerwona, HIGH);  // Świecimy tylko na czerwono
  delay(2000);
  digitalWrite(czerwona, LOW);   // Świecimy tylko na zielono
  digitalWrite(zielona, HIGH);
  delay(2000);
  digitalWrite(zielona, LOW);    // Świecimy tylko na niebiesko
  digitalWrite(niebieska, HIGH);
  delay(2000);
  digitalWrite(niebieska, LOW);

  digitalWrite(czerwona, HIGH);  // Świecimy każdą po kolei, bez gaszenia poprzednich
  delay(2000);
  digitalWrite(zielona, HIGH);
  delay(2000);
  digitalWrite(niebieska, HIGH);
  delay(2000);

  digitalWrite(czerwona, LOW);   // Wyłączamy wszystkie diody
  digitalWrite(niebieska, LOW);
  digitalWrite(zielona, LOW);
  delay(2000);
}
```
</Code>

### 3.2 Podłączanie wielu diod RGB

Do jednego Arduino możemy podłączyć wiele tradycyjnych diod RGB — każda potrzebuje swoich pinów. Poniżej przykład z dwiema diodami na pinach 3, 5, 6 oraz 9, 10, 11:

<Schematic
  src="/img/lekcje/14.16-schemat-dwie-diody-rgb.jpg"
  caption="Dwie diody RGB podłączone do Arduino — każda na osobnych pinach PWM."
  alt="Schemat Fritzing: dwie diody RGB podłączone do pinów 3,5,6 i 9,10,11"
  width={700}
  height={500}
/>

<Code lang="cpp" file="rgb-dwie-diody.ino">
```cpp
// Definicja wyprowadzeń pierwszej diody
#define czerwona  3
#define zielona   5
#define niebieska 6

// Definicja wyprowadzeń drugiej diody
#define czerwona2  9
#define zielona2  10
#define niebieska2 11

void setup() {
  pinMode(czerwona, OUTPUT);   // Konfiguracja wyprowadzeń jako wyjścia
  pinMode(zielona, OUTPUT);
  pinMode(niebieska, OUTPUT);
  pinMode(czerwona2, OUTPUT);
  pinMode(zielona2, OUTPUT);
  pinMode(niebieska2, OUTPUT);
}

void loop() {
  digitalWrite(czerwona, HIGH);   // Miganie diodami z użyciem różnych kolorów
  digitalWrite(zielona2, HIGH);
  delay(1000);
  digitalWrite(czerwona, LOW);
  digitalWrite(zielona2, LOW);
  digitalWrite(niebieska, HIGH);
  digitalWrite(czerwona2, HIGH);
  delay(1000);
  digitalWrite(niebieska, LOW);
  digitalWrite(czerwona2, LOW);
}
```
</Code>

<Callout type="note" title="Limity pinów PWM w Arduino UNO">
Arduino UNO posiada tylko **6 pinów PWM**: 3, 5, 6, 9, 10, 11. Dwie diody RGB zajmują wszystkie sześć — przy trzech tradycyjnych diodach RGB brakowałoby pinów. To jeden z powodów, dla których diody WS2812 są praktyczniejsze przy większych projektach.
</Callout>

### 3.3 Mieszanie kolorów za pomocą PWM

Funkcja `analogWrite(pin, wartość)` ustawia wypełnienie PWM w zakresie 0–255. Możemy dzięki temu płynnie regulować jasność każdego kanału i mieszać kolory. Poniższy szkic płynnie zmienia kolory obu diod w pętli:

<Schematic
  src="/img/lekcje/14.17-schemat-diody-rgb-pwm.jpg"
  caption="Układ z dwiema diodami RGB gotowy do mieszania kolorów przez PWM."
  alt="Schemat Fritzing dla płynnej zmiany kolorów dwóch diod RGB"
  width={700}
  height={500}
/>

<Code lang="cpp" file="rgb-mieszanie-kolorow.ino">
```cpp
// Definicja wyprowadzeń pierwszej diody
#define czerwona  3
#define zielona   5
#define niebieska 6

// Definicja wyprowadzeń drugiej diody
#define czerwona2  9
#define zielona2  10
#define niebieska2 11

void setup() {
  pinMode(czerwona, OUTPUT);   // Konfiguracja wyprowadzeń jako wyjścia
  pinMode(zielona, OUTPUT);
  pinMode(niebieska, OUTPUT);
  pinMode(czerwona2, OUTPUT);
  pinMode(zielona2, OUTPUT);
  pinMode(niebieska2, OUTPUT);
}

void loop() {
  int zmiana = 0;

  for (zmiana = 0; zmiana < 255; zmiana++) { // Płynna zmiana kolorów
    analogWrite(czerwona, 0);
    analogWrite(zielona, zmiana);
    analogWrite(niebieska, 255 - zmiana);

    analogWrite(czerwona2, zmiana);
    analogWrite(zielona2, 255 - zmiana);
    analogWrite(niebieska2, 0);

    delay(10); // Krótkie opóźnienie, aby efekt był widoczny dla ludzkiego oka
  }
}
```
</Code>

```cpp
// Definicja wyprowadzeń pierwszej diody
#define czerwona  3
#define zielona   5
#define niebieska 6

// Definicja wyprowadzeń drugiej diody
#define czerwona2  9
#define zielona2  10
#define niebieska2 11

void setup() {
  pinMode(czerwona, OUTPUT);   // Konfiguracja wyprowadzeń jako wyjścia
  pinMode(zielona, OUTPUT);
  pinMode(niebieska, OUTPUT);
  pinMode(czerwona2, OUTPUT);
  pinMode(zielona2, OUTPUT);
  pinMode(niebieska2, OUTPUT);

  randomSeed(analogRead(A5)); // Ziarno dla generatora liczb losowych
}

void loop() {
  int zmiana = 0;
  int zmianaLosowa = random(255);

  for (zmiana = 0; zmiana < 255; zmiana++) { // Płynna zmiana kolorów
    analogWrite(czerwona, zmianaLosowa);
    analogWrite(zielona, zmiana);
    analogWrite(niebieska, 255 - zmiana);

    analogWrite(czerwona2, zmiana);
    analogWrite(zielona2, 255 - zmiana);
    analogWrite(niebieska2, zmianaLosowa);

    delay(10);
  }
}
```
</Code>

Dodanie drugiej pętli `for` ze zmniejszającą się zmienną `zmiana` sprawia, że kolory zmieniają się płynnie tam i z powrotem:

<Code lang="cpp" file="rgb-animacja-obu-kierunkach.ino">
```cpp
// Definicja wyprowadzeń (identyczne jak poprzednio)
#define czerwona  3
#define zielona   5
#define niebieska 6
#define czerwona2  9
#define zielona2  10
#define niebieska2 11

void setup() {
  pinMode(czerwona, OUTPUT);
  pinMode(zielona, OUTPUT);
  pinMode(niebieska, OUTPUT);
  pinMode(czerwona2, OUTPUT);
  pinMode(zielona2, OUTPUT);
  pinMode(niebieska2, OUTPUT);

  randomSeed(analogRead(A5)); // Ziarno dla generatora liczb losowych
}

void loop() {
  int zmiana = 0;
  int zmianaLosowa = random(255);

  for (zmiana = 0; zmiana < 255; zmiana++) {  // Płynna zmiana kolorów "w przód"
    analogWrite(czerwona, zmianaLosowa);
    analogWrite(zielona, zmiana);
    analogWrite(niebieska, 255 - zmiana);

    analogWrite(czerwona2, zmiana);
    analogWrite(zielona2, 255 - zmiana);
    analogWrite(niebieska2, zmianaLosowa);

    delay(10);
  }

  for (zmiana = 255; zmiana > 0; zmiana--) { // Płynna zmiana kolorów "wstecz"
    analogWrite(czerwona, zmianaLosowa);
    analogWrite(zielona, zmiana);
    analogWrite(niebieska, 255 - zmiana);

    analogWrite(czerwona2, zmiana);
    analogWrite(zielona2, 255 - zmiana);
    analogWrite(niebieska2, zmianaLosowa);

    delay(10);
  }
}
```

## 4. Diody programowalne WS2812

Skoro tradycyjna dioda RGB wymaga 3 pinów, obsłużenie 8 diod wymagałoby 24 pinów — Arduino UNO ma ich tylko 14 cyfrowych! Tutaj z pomocą przychodzą diody WS2812.

<Photo
  file="14.20-pasek-ws2812.jpg"

  alt="Pasek taśmy LED z diodami WS2812"

/>

<Photo
  file="14.21-dioda-ws2812.jpg"
  caption="Pojedyncza dioda WS2812 — wbudowany sterownik i złącze danych."
  alt="Zbliżenie na pojedynczą diodę WS2812 z widocznym układem scalonym"
  width={400}

Każda dioda WS2812 zawiera miniaturowy sterownik, który:
1. Odbiera dane z Arduino przez **jeden przewód danych**.
2. Odczytuje własny kolor (24 bity: 8 bitów R, 8 G, 8 B).
3. **Przekazuje dalej** pozostałe dane do następnej diody w szeregu.

Dzięki temu do sterowania 8 (lub 800) diod wystarczy **jeden pin Arduino**.

### 4.1 Podłączenie diod WS2812

Moduł linijki WS2812 (8 diod) mocujemy w płytce stykowej. Masę łączymy z GND, zasilanie +5V z magistralą +5V, a przewód danych (DIN) z pinem A0 Arduino.

Przy intensywnych efektach świetlnych stosuj zewnętrzne zasilanie 5 V.

<Expandable title="Dlaczego indeksowanie od zera?" heading="####">

W bibliotece NeoPixel (i w C++ ogólnie) tablice i kolekcje numerowane są od **zera**. Pierwsza dioda to indeks `0`, ósma to indeks `7`. Próba ustawienia `setPixelColor(8, ...)` przy 8-diodowej linijce **nie spowoduje błędu** — ale nic nie zaświeci (dioda o indeksie 8 nie istnieje). Zawsze sprawdzaj, czy indeks mieści się w zakresie `0..n-1`.

## 5. Sygnalizator alarmowy

Mając linijkę WS2812, możemy w kilku linijkach kodu zbudować efektowny sygnalizator. Poniższy szkic zmienia kolor wszystkich 8 diod jednocześnie między czerwonym a niebieskim, naśladując sygnał policyjny:

<Code lang="cpp" file="sygnalizator-wszystkie.ino">
```cpp
#include <Adafruit_NeoPixel.h> // Dołączenie biblioteki

Adafruit_NeoPixel linijka = Adafruit_NeoPixel(8, A0, NEO_GRB + NEO_KHZ800);

void setup() {
  linijka.begin(); // Inicjalizacja
  linijka.show();
}

void loop() {
  int i = 0;
  for (i = 0; i < 8; i++) {
    linijka.setPixelColor(i, linijka.Color(255, 0, 0)); // Wszystkie diody czerwone
  }
  linijka.show();
  delay(250);

  for (i = 0; i < 8; i++) {
    linijka.setPixelColor(i, linijka.Color(0, 0, 255)); // Wszystkie diody niebieskie
  }
  linijka.show();
  delay(250);
}
```
</Code>

### Sygnalizator — wersja sekwencyjna

Bardziej realistyczny efekt uzyskamy, zapalając diody kolejno zamiast wszystkich naraz:

<Code lang="cpp" file="sygnalizator-sekwencja.ino">
```cpp
#include <Adafruit_NeoPixel.h> // Dołączenie biblioteki

Adafruit_NeoPixel linijka = Adafruit_NeoPixel(8, A0, NEO_GRB + NEO_KHZ800);

void setup() {
  linijka.begin(); // Inicjalizacja
  linijka.show();
}

void loop() {
  int i = 0;
  for (i = 0; i < 8; i++) {
    if (i < 4) {
      linijka.setPixelColor(i, linijka.Color(255, 0, 0)); // Diody 0–3 czerwone
    } else {
      linijka.setPixelColor(i, linijka.Color(0, 0, 255)); // Diody 4–7 niebieskie
    }
    linijka.show();
    delay(100); // Krótkie opóźnienie po każdej diodzie
  }
  linijka.clear(); // Zgaś wszystkie przed następnym obiegiem
}
```
</Code>

## Podsumowanie

Tradycyjna dioda RGB wymaga trzech pinów PWM i trzech rezystorów — za to jest prosta i nie wymaga żadnej biblioteki. Przez `analogWrite()` w zakresie 0–255 na każdym kanale R, G, B możemy uzyskać dowolny kolor świetlny. Dioda programowalna WS2812 idzie o krok dalej: wbudowany sterownik pozwala adresować każdą diodę z osobna przez jeden przewód danych i bibliotekę NeoPixel. Kluczowe do zapamiętania: zawsze po `setPixelColor()` wywołuj `show()`, inaczej zmiany nie trafią do diod. Przy intensywnych efektach świetlnych na wielu diodach WS2812 korzystaj z zewnętrznego zasilania 5 V — każda dioda przy pełnej bieli pobiera nawet 60 mA.
