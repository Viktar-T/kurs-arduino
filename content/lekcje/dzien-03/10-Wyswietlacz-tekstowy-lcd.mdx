## 1. Krótki wstęp o wyświetlaczach

Wyświetlacz tekstowy LCD 2×16 ma dwa wiersze po 16 znaków. Każdy znak składa się z pikseli, ale my nie sterujemy nimi pojedynczo. Wyświetlacz ma własny sterownik, który wie, jak narysować litery, cyfry i kilka symboli.

W tej lekcji używamy monochromatycznego wyświetlacza tekstowego zgodnego ze sterownikiem **HD44780**. To bardzo popularny standard, dlatego Arduino ma gotową bibliotekę do jego obsługi.

## 2. Piny wyświetlacza LCD 2×16

Typowy moduł LCD ma 16-pinowe złącze. Część pinów odpowiada za zasilanie, część za sterowanie, część za dane, a dwa ostatnie za podświetlenie ekranu.

<Schematic

  alt="Wyświetlacz tekstowy LCD 2x16 z opisem pinów"

/>

LCD zgodny z HD44780 może pracować w trybie 8-bitowym lub 4-bitowym. W trybie 8-bitowym potrzeba więcej przewodów. W kursie używamy trybu 4-bitowego, bo oszczędza piny Arduino i nadal pozwala korzystać z najważniejszych funkcji.

<Expandable title="Tryb 4-bitowy kontra 8-bitowy — jak to działa?" heading="####">

Sterownik HD44780 przyjmuje dane w bajtach (8 bitów na raz). W **trybie 8-bitowym** wszystkie 8 linii danych (D0–D7) jest podłączonych do Arduino i każdy bajt jest wysyłany jednym impulsem na linii E.

W **trybie 4-bitowym** używamy tylko linii D4–D7. Jeden bajt jest wysyłany w dwóch etapach: najpierw starsze 4 bity (nibble), potem młodsze 4 bity. Biblioteka `LiquidCrystal` robi to automatycznie — z perspektywy programu oba tryby działają identycznie.

Tryb 4-bitowy jest popularniejszy, bo oszczędza 4 piny Arduino. Te piny można przeznaczyć na przyciski, czujniki lub inne peryferia. Prędkość przesyłania danych do wyświetlacza jest w obu przypadkach wystarczająca dla tekstu, który zmienia się wolno.

</Expandable>

## 4. Pierwszy program: wyświetlanie tekstu

Do obsługi LCD używamy biblioteki `LiquidCrystal`. Najpierw dołączamy bibliotekę, potem tworzymy obiekt `lcd`, w którym podajemy piny Arduino połączone z wyświetlaczem.

<Code lang="cpp" file="lcd-pierwszy-tekst.ino">
```cpp
#include <LiquidCrystal.h>

LiquidCrystal lcd(2, 3, 4, 5, 6, 7);

void setup() {
  lcd.begin(16, 2);

  lcd.setCursor(0, 0);
  lcd.print("Kurs Arduino");

  lcd.setCursor(0, 1);
  lcd.print("Na Forbocie!");
}

void loop() {
}
```
</Code>

`lcd.begin(16, 2)` informuje bibliotekę, że pracujemy z wyświetlaczem 16 znaków na 2 wiersze. `lcd.setCursor(kolumna, wiersz)` ustawia miejsce pisania. Numeracja zaczyna się od zera, więc `(0, 0)` to pierwszy znak pierwszego wiersza, a `(0, 1)` to pierwszy znak drugiego wiersza.

<Photo
  file="10.05-lcd-pierwszy-tekst-arduino.jpg"
  day="dzien-01"
  caption="Pierwszy tekst wyświetlony na LCD z Arduino."
  alt="Wyświetlacz LCD pokazujący tekst Kurs Arduino i Na Forbocie"
  width={800}

/>

<Callout type="warning" title="Co jeśli nie działa?">
Sprawdź kolejno: zasilanie LCD, masę, kolejność przewodów sygnałowych, zgodność pinów w `LiquidCrystal lcd(...)` oraz ustawienie kontrastu. Te punkty rozwiązują większość problemów z pierwszym uruchomieniem LCD.
</Callout>

<Expandable title="Własne znaki na LCD — lcd.createChar()" heading="####">

Sterownik HD44780 ma pamięć na **8 własnych znaków** w slotach 0–7. Każdy znak to siatka **5×8 pikseli**. Możesz zaprojektować własne ikony: strzałki, symbol stopnia Celsjusza, baterię czy proste emoji.

Każdy znak jest tablicą 8 bajtów — jeden bajt to jeden wiersz siatki. Bity 0–4 każdego bajtu odpowiadają kolumnom (bit 4 to lewa kolumna, bit 0 to prawa). Wypełniony prostokąt wyglądałby tak: `{0x1F, 0x1F, 0x1F, 0x1F, 0x1F, 0x1F, 0x1F, 0x1F}`.

Znak wgrywasz przez `lcd.createChar(numer, tablica)` w `setup()`, a wyświetlasz przez `lcd.write(numer)`. Projektowanie wzorów ułatwiają generatory online — wystarczy wyszukać „HD44780 custom char generator".

</Expandable>

## 5. Kursor i miganie kursora

Wyświetlacz LCD może pokazywać kursor. Domyślnie jest on wyłączony. Funkcja `lcd.cursor()` włącza podkreślenie w miejscu kursora, a `lcd.noCursor()` je wyłącza.

<Code lang="cpp" file="lcd-kursor.ino">
```cpp
#include <LiquidCrystal.h>

LiquidCrystal lcd(2, 3, 4, 5, 6, 7);

void setup() {
  lcd.begin(16, 2);
  lcd.setCursor(0, 0);
  lcd.print("Kurs Arduino");
  lcd.setCursor(0, 1);
  lcd.print("Na Forbocie!");
  lcd.cursor();
}

void loop() {
}
```
</Code>

## 6. Włączanie, wyłączanie i czyszczenie ekranu

Funkcje `lcd.display()` i `lcd.noDisplay()` włączają lub wyłączają widoczność tekstu. Nie kasują pamięci wyświetlacza i nie sterują podświetleniem. Po ponownym włączeniu tekst wraca.

<Code lang="cpp" file="lcd-display-nodisplay.ino">
```cpp
#include <LiquidCrystal.h>

LiquidCrystal lcd(2, 3, 4, 5, 6, 7);

void setup() {
  lcd.begin(16, 2);
  lcd.setCursor(0, 0);
  lcd.print("Kurs Arduino");
  lcd.setCursor(0, 1);
  lcd.print("Na Forbocie!");
}

void loop() {
  lcd.noDisplay();
  delay(500);

  lcd.display();
  delay(500);
}
```
</Code>

<Photo
  file="10.08-lcd-wlaczanie-wylaczanie-wyswietlacza.gif"
  day="dzien-01"
  caption="lcd.noDisplay() ukrywa tekst, a lcd.display() pokazuje go ponownie."
  alt="Animacja chwilowego wyłączania tekstu na LCD"

Do kasowania zawartości służy `lcd.clear()`. Nie warto jednak czyścić ekranu w każdym obiegu pętli bez potrzeby, bo może to powodować miganie i utrudniać odczyt.

<Task title="Zadanie 2" estimate="10 min">

</Task>

## 7. Wynik ADC na wyświetlaczu

LCD pozwala pokazać wynik pomiaru bez komputera. W przykładzie fotorezystor i rezystor tworzą dzielnik napięcia, którego wyjście podłączamy do `A0`. Program przelicza wynik ADC na napięcie i pokazuje go w drugiej linii LCD.

<Schematic
  src="/img/lekcje/dzien-01/10.09-lcd-czujnik-swiatla-schemat.png"
  caption="Fotorezystor z rezystorem tworzy dzielnik napięcia podłączony do A0."
  alt="Schemat podłączenia czujnika światła do Arduino i LCD"
  width={444}
  height={680}
/>

<Code lang="cpp" file="lcd-pomiar-napiecia.ino">
```cpp
#include <LiquidCrystal.h>

LiquidCrystal lcd(2, 3, 4, 5, 6, 7);
double odczyt;

void setup() {
  lcd.begin(16, 2);
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("Nap. odczytane");

  lcd.setCursor(0, 1);
  lcd.print("0.00V");
}

void loop() {
  odczyt = analogRead(A0) * 5.0 / 1024.0;

  lcd.setCursor(0, 1);
  lcd.print(odczyt);
  lcd.print("V ");

  delay(250);
}
```
</Code>

<Photo
  file="10.10-lcd-pomiar-napiecia-fotorezystor.jpg"

Zwróć uwagę, że stały tekst pierwszej linii wpisujemy tylko raz w `setup()`. W pętli aktualizujemy tylko fragment z wynikiem. To ogranicza miganie i sprawia, że ekran jest czytelniejszy.

</Task>

## 8. Podświetlenie LCD i PWM

Podświetlenie LCD to dioda LED wbudowana w moduł. W wielu wyświetlaczach jest już rezystor ograniczający prąd, ale nie należy zakładać tego bez sprawdzenia dokumentacji lub pomiaru prądu. Dla bezpieczeństwa można użyć rezystora albo tranzystora.

<Schematic
  src="/img/lekcje/dzien-01/10.11-lcd-sterowanie-podswietleniem-pwm.png"
  caption="Podświetlenie LCD można sterować z pinu PWM, ale trzeba pilnować prądu."
  alt="Schemat sterowania podświetleniem LCD z Arduino przez pin PWM"
  width={492}
  height={662}
/>

<Callout type="hazard" title="Sprawdź prąd podświetlenia">
Pin Arduino nie jest zasilaczem dużej mocy. Jeśli nie wiesz, ile prądu pobiera podświetlenie LCD, użyj rezystora ograniczającego prąd albo tranzystora sterującego.
</Callout>

Jeśli podświetlenie jest bezpiecznie podłączone do pinu PWM, możemy płynnie zmieniać jasność przez `analogWrite()`.

<Code lang="cpp" file="lcd-pwm-podswietlenie.ino">
```cpp
#include <LiquidCrystal.h>

LiquidCrystal lcd(2, 3, 4, 5, 6, 7);

int jasnosc = 0;
int zmiana = 5;

void setup() {
  lcd.begin(16, 2);
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("Witaj na");
  lcd.setCursor(0, 1);
  lcd.print("FORBOT.pl");
}

void loop() {
  analogWrite(11, jasnosc);

  jasnosc = jasnosc + zmiana;

  if (jasnosc == 0 || jasnosc == 255) {
    zmiana = -zmiana;
  }

  delay(30);
}
```
</Code>

<Expandable title="Moduł I2C do LCD — ten sam wyświetlacz, dużo mniej przewodów" heading="####">

Zamiast 6–10 przewodów sygnałowych można użyć **modułu I2C do LCD** — małej płytki z ekspanderem portów PCF8574, którą przykręca się bezpośrednio do złącza LCD. Taki moduł komunikuje się z Arduino przez tylko **dwie linie: SDA i SCL** (plus zasilanie i masę).

Biblioteka `LiquidCrystal_I2C` (dostępna w Menedżerze bibliotek Arduino IDE) działa niemal identycznie jak `LiquidCrystal`. Zamiast `LiquidCrystal lcd(2,3,4,5,6,7)` piszesz `LiquidCrystal_I2C lcd(0x27, 16, 2)`, gdzie `0x27` to domyślny adres I2C modułu (może być też `0x3F` — sprawdzasz skanerem I2C).

Moduł I2C jest szczególnie przydatny, gdy brakuje Ci wolnych pinów cyfrowych. Wadą jest drobne opóźnienie transmisji I2C, ale przy wolno zmieniającym się tekście jest ono zupełnie niezauważalne.

</Expandable>

## Podsumowanie

Wyświetlacz LCD 2×16 pozwala Arduino prezentować informacje bez komputera. Wiesz już, czym jest sterownik HD44780, jak podłączyć LCD w trybie 4-bitowym, jak użyć biblioteki `LiquidCrystal`, ustawiać kursor, czyścić ekran i aktualizować tylko wybrane fragmenty tekstu. Potrafisz też pokazać wynik ADC na LCD oraz rozumiesz, że podświetlenie trzeba traktować jak zwykłą diodę LED z ograniczeniem prądu.
