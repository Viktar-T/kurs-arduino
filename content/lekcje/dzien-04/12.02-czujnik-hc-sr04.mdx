## 1. Czujnik ultradźwiękowy HC-SR04

### Zasada działania

1. Na pin `Trig` podajemy impuls wysoki trwający **10 µs (mikrosekundy)** — czujnik wysyła 8 impulsów ultradźwiękowych.
2. Pin `Echo` przechodzi w stan wysoki i pozostaje tam przez czas proporcjonalny do zmierzonej odległości.
3. Mierzymy czas trwania stanu wysokiego na `Echo` — to czas podróży dźwięku (tam i z powrotem).
4. Dzielimy przez `58`, żeby otrzymać odległość w centymetrach.

<Expandable title="Ograniczenia i martwa strefa czujnika HC-SR04" heading="####">

HC-SR04 to prosty i tani czujnik, ale ma kilka praktycznych ograniczeń:

- **Martwa strefa:** obiekt bliższy niż ok. `2–3 cm` nie zostanie wykryty — echo wraca zbyt szybko, zanim czujnik zdąży przełączyć się w tryb nasłuchiwania.
- **Maksymalny zasięg:** producent deklaruje ok. `400 cm`, ale powyżej `200–250 cm` pomiary stają się niestabilne.
- **Kąt wiązki:** czujnik „widzi" stożek o półkącie ok. `15°`. Obiekt pod dużym skosem może odbić sygnał w bok i nie wrócić do czujnika.
- **Materiały pochłaniające:** miękkie powierzchnie (tkaniny, piana, futro) pochłaniają ultradźwięki i zwracają słabe echo lub w ogóle go nie zwracają.
- **Fałszywe echa:** w pomieszczeniach z wieloma powierzchniami echo może wielokrotnie odbijać się od ścian. `pulseIn()` chwyta pierwsze echo — zazwyczaj poprawne, ale przy skomplikowanej geometrii mogą pojawiać się skoki odczytu.

</Expandable>

Zaczynamy od pełnego programu: wyzwalamy pomiar, mierzymy czas echa funkcją `pulseIn()` i przeliczamy wynik na centymetry. Opis `pulseIn()` znajdziesz też w [dokumentacji Arduino](https://docs.arduino.cc/language-reference/?_gl=1*kpmpc9*_up*MQ..*_ga*MzU5ODg2ODMwLjE3NzkxMTA4ODE.*_ga_NEXN8H46L5*czE3NzkxODQ2OTAkbzIkZzAkdDE3NzkxODQ2OTAkajYwJGwwJGg2NzQyMTQzNzk.):

<Expandable title="Jak działa pulseIn()?" heading="####">

`pulseIn(pin, HIGH)` czeka, aż na wskazanym pinie pojawi się stan wysoki, mierzy czas trwania tego stanu i zwraca wynik w mikrosekundach. W przypadku HC-SR04 ten czas odpowiada temu, jak długo impuls `Echo` był w stanie wysokim.

Jeśli użyjesz `pulseIn(echoPin, HIGH)`, Arduino mierzy czas od początku do końca impulsu na pinie `echoPin`. Im dłużej wraca echo ultradźwiękowe, tym dłuższy impuls i większa zmierzona odległość.

Funkcja może też otrzymać trzeci argument — limit oczekiwania:

```cpp
czas = pulseIn(echoPin, HIGH, 25000);
```

Wtedy Arduino czeka maksymalnie `25000 µs`. Jeśli impuls nie nadejdzie w tym czasie, funkcja zwróci `0`, a program nie będzie blokowany przez domyślne, dłuższe oczekiwanie.

</Expandable>

<Code lang="cpp" file="hc-sr04-dystans-cm.ino">
```cpp
const byte trigPin = 12;
const byte echoPin = 11;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  long czas, dystans;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  czas = pulseIn(echoPin, HIGH);
  dystans = czas / 58;

  Serial.print(dystans);
  Serial.println(" cm");

  delay(500);
}
```
</Code>

<Callout type="note" title="Skąd wzięło się 58?">
Dźwięk przebywa w powietrzu ok. 340 m/s. Impuls pokonuje dystans dwukrotnie (tam i z powrotem), a `pulseIn()` zwraca czas w mikrosekundach. Dzielenie przez 58 daje przybliżenie odległości w centymetrach: 1 cm = 58 µs.
</Callout>

<Expandable title="Kompensacja temperatury — kiedy dzielnik 58 nie wystarczy" heading="####">

Prędkość dźwięku w powietrzu zależy od temperatury. Wzór przybliżony:

> v ≈ 331,3 + 0,606 × T [m/s]

Przy `20 °C` wynosi ok. `343 m/s`, a przy `0 °C` ok. `331 m/s`. Dzielnik `58` odpowiada temperaturze pokojowej — przy mrozie lub upale wynik jest nieco zaburzony.

W sali szkolnej różnica temperatury między zimą a latem to ok. `20 °C`, co przekłada się na błąd pomiaru ok. `3%`. Przy zasięgu `100 cm` to ok. `3 cm` — często pomijalne, ale przy precyzyjnym omijaniu przeszkód warto mieć to z tyłu głowy.

</Expandable>

## 3. Funkcja zwracająca odległość

<Task title="Zadanie 3" estimate="10 min">
Zamknijmy cały pomiar w jednej funkcji — kod `loop()` będzie wtedy bardzo przejrzysty:

<Expandable title="Przykład rozwiązania" heading="####">

<Code lang="cpp" file="hc-sr04-funkcja.ino">
```cpp
const byte trigPin = 12;
const byte echoPin = 11;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  Serial.print(zmierzOdleglosc());
  Serial.println(" cm");
  delay(500);
}

int zmierzOdleglosc() {
  long czas, dystans;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  czas = pulseIn(echoPin, HIGH);
  dystans = czas / 58;

  return dystans;
}
```

<Expandable title="Uśrednianie pomiarów — stabilniejsze wskazania" heading="####">

Pojedynczy odczyt HC-SR04 może czasem „skoczyć" o kilka centymetrów z powodu przypadkowego echa lub drgań zasilania. Uśrednianie kilku pomiarów znacząco poprawia stabilność:

```cpp
int zmierzOdlegloscUsredniona(int probek) {
  long suma = 0;
  for (int i = 0; i < probek; i++) {
    suma += zmierzOdleglosc();
    delay(20);
  }
  return suma / probek;
}
```

Wywołanie `zmierzOdlegloscUsredniona(5)` pobiera `5` pomiarów i zwraca ich średnią. Jedno `delay(20)` to `20 ms` przerwy między próbkami — pięć próbek zajmuje łącznie ok. `100 ms`. Im więcej próbek, tym wolniejsza reakcja programu. W robotach mobilnych `3`–`5` pomiarów to zazwyczaj dobry kompromis między stabilnością odczytu a szybkością reagowania na przeszkody.

## 4. Sprawdzanie zakresu odległości

Możemy napisać funkcję `zakres()`, która sprawdza, czy zmierzona odległość mieści się w podanym przedziale, i reaguje stanem pinu (np. buzzera lub diody):

<Code lang="cpp" file="hc-sr04-zakres.ino">
```cpp
// PIN_BUZZER = 2
void zakres(int a, int b) {
  int jakDaleko = zmierzOdleglosc();
  if ((jakDaleko > a) && (jakDaleko < b)) {
    digitalWrite(PIN_BUZZER, HIGH);
  } else {
    digitalWrite(PIN_BUZZER, LOW);
  }
}
```
</Code>

```cpp
const byte trigPin   = 12;
const byte echoPin   = 11;
const byte PIN_BUZZER = 2;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin,    OUTPUT);
  pinMode(echoPin,    INPUT);
  pinMode(PIN_BUZZER, OUTPUT);
}

void loop() {
  zakres(10, 25);
  delay(100);
}

int zmierzOdleglosc() {
  long czas, dystans;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  czas = pulseIn(echoPin, HIGH);
  dystans = czas / 58;

  return dystans;
}

void zakres(int a, int b) {
  int jakDaleko = zmierzOdleglosc();
  if ((jakDaleko > a) && (jakDaleko < b)) {
    digitalWrite(PIN_BUZZER, HIGH);
  } else {
    digitalWrite(PIN_BUZZER, LOW);
  }
}
```
</Code>

## Podsumowanie

Czujnik HC-SR04 mierzy odległość ultradźwiękami: krótki impuls na `Trig`, pomiar czasu echa na `Echo` przez `pulseIn()`, przeliczenie przez `58` — i masz odległość w centymetrach. Zamknięcie pomiaru w funkcji `zmierzOdleglosc()` dało przejrzysty program alarmu zbliżeniowego, w którym `loop()` robi jedną rzecz: sprawdza zakres.
