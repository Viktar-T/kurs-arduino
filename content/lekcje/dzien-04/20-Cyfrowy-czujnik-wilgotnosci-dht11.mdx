## 1. Czym jest wilgotność względna?

<Photo
  file="20.02-czym-jest-wilgotnosc.png"
  caption="Wilgotność względna opisuje ilość pary wodnej w powietrzu w stosunku do maksymalnej możliwej przy danej temperaturze."
  alt="Schemat ilustrujący pojęcie wilgotności względnej"
/>

Czujnik DHT-11 mierzy **wilgotność względną**, oznaczaną skrótem **RH** (od ang. *Relative Humidity*). Wartość ta określa, ile wody znajduje się w powietrzu względem maksymalnej ilości, jaką powietrze może pomieścić w danej temperaturze.

Wilgotność względną wyraża się w **%RH** — w zakresie od 0 do 100:
- **0 %RH** — powietrze całkowicie suche,
- **100 %RH** — powietrze nasycone parą wodną, powyżej tej wartości woda zaczyna się skraplać.

<Callout type="note" title="Wilgotność a temperatura">
Ilość wody, którą powietrze może pomieścić, zależy od jego temperatury — dlatego przy tej samej ilości pary wodnej w zimnym pomieszczeniu %RH będzie wyższe niż w ciepłym. Z tego powodu DHT-11 mierzy **jednocześnie** temperaturę i wilgotność.
</Callout>

## 2. Czujnik DHT-11 w praktyce

<Photo
  file="20.03-dht11-czujnik.png"
  caption="Czujnik DHT-11 w niebieskiej obudowie — łączy termometr i czujnik wilgotności w jednym module."
  alt="Widok czujnika DHT-11 w niebieskiej obudowie"
/>

DHT-11 to popularny, tani czujnik cyfrowy dostępny w niebieskiej obudowie z czterema wyprowadzeniami. Trzy z nich są używane: **VCC**, **DATA** i **GND**. Czwarty pin oznaczony **NC** (*Not Connected*) można zignorować.

Czujnik korzysta z **zmodyfikowanego interfejsu jednoprzewodowego**, który **nie jest zgodny** ze standardem 1-Wire (używanym np. przez DS18B20). Nie próbuj używać biblioteki 1-Wire z DHT-11 — będziesz potrzebować dedykowanej biblioteki.

## 3. Podłączenie DHT-11 do Arduino

Podłączenie jest bardzo proste — czujnik ma tylko jeden pin danych. Konieczny jest jednak **rezystor podciągający 4,7 kΩ** łączący linię DATA z szyną zasilania VCC.

  alt="Schemat Fritzing pokazujący podłączenie DHT-11 do Arduino UNO"
/>

<Photo
  file="20.08-dht11-zblizenie.jpg"

  alt="Zbliżenie na wyprowadzenia czujnika DHT-11 podłączonego do płytki stykowej"

Połączenia:
- **VCC** → **5 V** Arduino
- **DATA** → **pin 2** Arduino (+ rezystor 4,7 kΩ do VCC)
- **NC** → niepodłączony
- **GND** → **GND** Arduino

## 4. Komunikacja z DHT-11 — biblioteka Mark Ruysa

Do obsługi DHT-11 użyjemy prostej biblioteki **arduino-DHT** autorstwa **Mark Ruysa**, dostępnej na GitHubie. Biblioteka automatycznie rozpoznaje typ czujnika (DHT-11, DHT-22, AM2302, RHT03) i obsługuje je identycznie.

### Instalacja biblioteki

1. Pobierz pliki z [github.com/markruys/arduino-DHT](https://github.com/markruys/arduino-DHT).

Zacznij od pustego szkieletu z dołączoną biblioteką, definicją pinu i inicjalizacją UART:

{

  // tu będą odczyty

## 5. Odczyt wilgotności i temperatury

Do odczytu służą dwie funkcje:
- `dht.getHumidity()` — zwraca wilgotność w **%RH** (typ `float`)
- `dht.getTemperature()` — zwraca temperaturę w **°C** (typ `float`)

Najprostszy program odczytujący i wyświetlający dane co sekundę:

<Code lang="cpp" file="dht11-podstawowy.ino">
```cpp
#include "DHT.h"
#define DHT11_PIN 2
DHT dht;

void setup()
{
  Serial.begin(9600);
  dht.setup(DHT11_PIN);
}

void loop()
{
  // Pobranie wilgotności
  int wilgotnosc = dht.getHumidity();
  Serial.print(wilgotnosc);
  Serial.print("%RH | ");

  // Pobranie temperatury
  int temperatura = dht.getTemperature();
  Serial.print(temperatura);
  Serial.println("*C");

  delay(1000); // Odczekanie wymaganego czasu między próbkami
}
```
</Code>

Wynik w Monitorze portu szeregowego wygląda następująco (poniżej animacja po chuchnięciu na czujnik — wilgotność wyraźnie rośnie):

<Photo
  file="20.09-dht11-demo-chuchniecie.gif"

  alt="Animacja GIF monitora portu szeregowego — wzrost wilgotności po chuchnięciu na czujnik"

<Callout type="note" title="DHT-11 reaguje wolno">
Czujnik potrzebuje **6–15 sekund** (typowo ~10 s) na zarejestrowanie zmiany wilgotności i temperatury. To cecha układu, nie błąd programu — nie przyspieszysz tego, skracając `delay()`.
</Callout>

## 6. Obsługa błędów odczytu

Czasem komunikacja z czujnikiem może się nie udać — w Monitorze pojawia się wtedy `0` dla obu wartości. Biblioteka udostępnia funkcje pomagające unikać takich problemów:

<Photo
  file="20.10-dht11-blad-odczytu.png"
  caption="Błąd odczytu wyświetla 0 dla wilgotności i temperatury — bez obsługi błędów trudno odróżnić go od prawidłowego wyniku."
  alt="Zrzut ekranu Monitora portu szeregowego z błędnym odczytem 0%RH i 0°C"
/>

Dwie przydatne funkcje:
- `dht.getStatusString()` — zwraca `"OK"` przy poprawnym odczycie lub np. `"TIMEOUT"` przy błędzie.
- `dht.getMinimumSamplingPeriod()` — zwraca wymagane opóźnienie między odczytami (w ms), różne dla DHT-11 i DHT-22.

Ulepszona wersja programu z obsługą błędów:

<Code lang="cpp" file="dht11-z-obsluga-bledow.ino">
```cpp
#include "DHT.h"
#define DHT11_PIN 2
DHT dht;

void setup()
{
  Serial.begin(9600);
  dht.setup(DHT11_PIN);
}

void loop()
{
  // Pobranie wartości
  int wilgotnosc = dht.getHumidity();
  int temperatura = dht.getTemperature();

  // Wyświetl tylko gdy odczyt jest poprawny
  if (dht.getStatusString() == "OK") {
    Serial.print(wilgotnosc);
    Serial.print("%RH | ");
    Serial.print(temperatura);
    Serial.println("*C");
  }

  // Odczekaj wymagany czas dla tego czujnika (nie "na sztywno")
  delay(dht.getMinimumSamplingPeriod());
}
```
</Code>

## 7. Przeliczanie na stopnie Fahrenheita

Biblioteka zawiera funkcję `dht.toFahrenheit(wartoscCelsjusza)`, która przelicza temperaturę na skalę Fahrenheita. Wywołanie wygląda tak:

<Code lang="cpp" file="dht11-fahrenheit.ino">
```cpp
// Dodaj do sekcji wyświetlania w loop():
Serial.print(dht.toFahrenheit(temperatura));
Serial.println("F");
```
</Code>

<Photo
  file="20.12-dht11-fahrenheit.gif"
  caption="Animacja: Monitor portu szeregowego wyświetla jednocześnie temperaturę w °C i °F."

<Expandable title="Wzór na przeliczenie Celsjusz → Fahrenheit" heading="###">
Biblioteka wykonuje standardowe przeliczenie: **F = (C × 9/5) + 32**. Przykładowo: 25 °C = 77 °F.
</Expandable>

<Callout type="tip" title="Jak używać Pomocnika AI do nauki programowania">
Czujnik DHT11 i wilgotność względna to temat, przy którym AI otworzy nieoczekiwane połączenia z fizyką i projektami:

- **Wilgotność względna i punkt rosy** — zapytaj AI: „Wytłumacz, czym jest wilgotność względna (%RH) i jak obliczyć punkt rosy (dew point) z temperatury i wilgotności. Podaj wzór Magnus". Zrozumiesz, co tak naprawdę mierzysz tym czujnikiem.
- **DHT11 z wyświetlaczem LCD** — poproś AI: „Napisz szkic Arduino, który odczytuje temperaturę i wilgotność z DHT11 i wyświetla je na LCD 2×16. Wyświetl °C i %RH na osobnych wierszach". To klasyczny projekt stacji pogodowej, który łączy materiał z kilku lekcji.
- **Stacja pogodowa z wieloma czujnikami** — gdy opanujesz DHT11, zapytaj AI: „Jak połączyć DHT11, DS18B20 i czujnik ciśnienia BMP280, żeby zbudować mini-stację pogodową z Arduino? Jakie biblioteki będą potrzebne?". AI zaprojektuje architekturę systemu i pokaże, jak integrować wiele czujników.
</Callout>

## 8. Ćwiczenia

<Task title="Zadanie — pomiar wilgotności z alertem" estimate="15 min">
Napisz program, który:
1. Odczytuje wilgotność i temperaturę z DHT-11 co sekundę.
2. Gdy wilgotność przekroczy **70 %RH**, włącza diodę LED (pin 13) jako sygnał ostrzeżenia.
3. Poniżej 70 %RH dioda jest wyłączona.
4. W Monitorze portu szeregowego wyświetla aktualny stan w formacie: `45%RH | 22*C | LED: OFF`.

Wskazówka: użyj `dht.getStatusString() == "OK"`, żeby nie reagować na błędne odczyty.
</Task>

<Task title="Zadanie rozszerzone — prosta stacja pogodowa" estimate="20 min">
Zbuduj prostą stację pogodową wyświetlającą w Monitorze portu co 2 sekundy:
- wilgotność w %RH,
- temperaturę w °C **i** °F,
- słowny opis wilgotności: `"sucho"` (< 40 %RH), `"komfortowo"` (40–70 %RH), `"wilgotno"` (> 70 %RH).

Pamiętaj o obsłudze błędów — wypisuj dane tylko gdy `getStatusString() == "OK"`.
</Task>

## Podsumowanie

Czujnik **DHT-11** mierzy **wilgotność względną** (0–100 %RH) i **temperaturę** (0–50 °C) przez jeden pin danych z rezystorem podciągającym 4,7 kΩ. Jego interfejs jest **niekompatybilny** ze standardem 1-Wire — wymaga dedykowanej biblioteki, np. **arduino-DHT** Mark Ruysa. Kluczowe funkcje biblioteki: `dht.setup(pin)`, `dht.getHumidity()`, `dht.getTemperature()`, `dht.getStatusString()` (obsługa błędów), `dht.getMinimumSamplingPeriod()` (automatyczne opóźnienie), `dht.toFahrenheit()`. Czujnik reaguje wolno — zmiana wilgotności jest widoczna po **6–15 sekundach**. Łącząc DHT-11 z wiedzą z poprzednich lekcji (termometry, fotorezystor, diody programowalne), możesz zbudować kompletną **stację pogodową** na Arduino.
